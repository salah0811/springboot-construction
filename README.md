## 🛠️ 技术架构预览

前端：Vue 3.x + Element Plus + Axios + ECharts + Three.js
后端：Spring Boot 2.7.x + MyBatis-Plus + Spring Security + JWT
数据库：MySQL 8.0 + Redis 6.x + MongoDB（BIM数据）
物联网：MQTT + EMQ + 传感器（扬尘/噪声/塔吊）
BIM引擎：Three.js + IFC.js（模型轻量化展示）
GIS服务：百度地图/高德地图API（项目分布、轨迹）
消息队列：RabbitMQ（告警通知、数据同步）
文件存储：阿里云OSS（图纸、模型、照片）
AI识别：Python + YOLO（安全帽识别、烟火检测）
部署：Docker + Nginx + Jenkins
